## Summary
Add a short, beginner-friendly walkthrough that takes a new user from generating the sample scene to viewing a wetland analysis result. Keep it focused on the existing Quick Start commands and explain what each step produces and where to find the result.

## Acceptance criteria
- A new user can follow the walkthrough using the documented sample dataset and ONNX model commands.
- The guide explains how to start the backend and frontend and how to launch one example analysis.
- Expected outputs and common setup pitfalls are described without requiring real satellite data.
- Existing Quick Start instructions remain accurate.

## Impact estimate
**Impact: Medium** — lowers the barrier to trying the application and helps new contributors verify their setup. **Effort: Small** — primarily documentation, with no GIS engine changes.
